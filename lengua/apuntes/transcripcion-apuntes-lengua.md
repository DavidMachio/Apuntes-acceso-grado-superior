## Imagen 1

**TEMA 1**

### • Estilo directo e indirecto

- Directo → se mantienen las palabras originales.
  Ejemplo: Cristina le dijo "trae el pan".
- Indirecto → se cuenta lo que una persona ha dicho.
  Ejemplo: Cristina le dijo a su hija que trajera el pan.

### • Palabras agudas, llanas y esdrújulas

- Agudas → la sílaba que suena más fuerte es la última. **Llevan tilde cuando terminan en vocal, N o S.**
- Llanas → la sílaba que suena más fuerte es la penúltima. **Llevan tilde cuando no terminan en vocal, N o S.**
- Esdrújulas → la sílaba que suena más fuerte es la antepenúltima. **Siempre llevan tilde.**

### • Vocales abiertas y cerradas

- Abiertas → A, E, O
- Cerradas → I, U

### • Diptongos

Es la unión de 2 vocales en una misma sílaba.

- Vocal cerrada + vocal cerrada
- Vocal abierta + vocal cerrada
- Vocal cerrada + vocal abierta

(huésped, murciélago)

### • Triptongos

Es la unión de 3 vocales en una misma sílaba.

- Vocal cerrada + vocal abierta + vocal cerrada.

(fastidiéis)

### • Ejercicios →

Césped, árbol, cántaro, imagen, cortés, robot, gramática, bíceps, ámbar, pésimo, pantalón.

### • Hiato

Es la separación en 2 sílabas distintas de 2 vocales que se escriben juntas.

- Vocal abierta + vocal abierta (teatro, leemos)
- Vocal abierta + vocal cerrada

En caso de que la tónica sea la cerrada, siempre lleva tilde. (fría, río, reír)

### • Tilde diacrítica

Los monosílabos no llevan tilde.
La tilde diacrítica sirve para distinguir palabras homófonas que pertenecen a distintas categorías gramaticales.

| Con tilde | Sin tilde |
|---|---|
| Él → pronombre personal | El → artículo |
| Tú → pronombre personal | Tu → adjetivo |
| Mí → pronombre personal | Mi → adjetivo |
| Sí → adverbio | Si → conjunción |
| Dé → verbo | De → preposición |
| Sé → verbo | Se → pronombre |
| Té → nombre | Te → pronombre |
| Más → adverbio | Mas → conjunción |
| Aún → adverbio | Aun → adverbio |

### • Texto

En la ribera del río, en una cabaña de piedras, vivía una familia muy pobre. Eran tan pobres que no había nunca que comer para todos, y al menos uno debía quedarse en ayunas. Los niños le preguntaban al abuelo:

¿Por qué no somos ricos? ¿Cuándo nos haremos ricos nosotros también?

El abuelo respondía:

Cuando el burro vuele.

Los niños se reían, pero algo creían. De vez en cuando iban al establo, donde el burro masticaba su paja, le acariciaban el lomo y le decían:

### • Comunicación verbal y no verbal

La comunicación es el proceso mediante el cual las personas intercambiamos información, pensamientos, ideas…

- Verbal → lenguaje hablado o escrito.
- No verbal → gestos, expresiones faciales, posturas.

## Imagen 4

### • Elementos de la comunicación

Emisor, receptor, mensaje, código, canal y contexto.

- Emisor → es quien emite el mensaje.
- Receptor → persona o entidad que recibe el mensaje transmitido por el emisor.
- Mensaje → información, idea o concepto que el emisor intenta transmitir al receptor.
- Código → conjunto de reglas y símbolos que el emisor y el receptor utilizan para entenderse (lenguaje).
- Canal → el medio a través del cual se transmite el mensaje.
- Contexto → entorno en el que se lleva a cabo la comunicación.

### • Esquema con elementos de comunicación de dos imágenes (ejercicios)

**Concierto:**

- Emisor → cantante o grupo
- Receptor → público
- Mensaje → canción
- Código → idioma
- Canal → voz / aire
- Contexto → concierto

**Mensaje de texto:**

- Emisor – Alberto
- Receptor – Carlos
- Mensaje – invitación al cine
- Código – idioma escrito
- Canal – WhatsApp o SMS
- Contexto – mensaje por teléfono
